# Segurança

Não publique vulnerabilidades, credenciais ou dados pessoais em issues públicas. Relatos devem ser enviados diretamente para **integridade@editoraroel.com.br**, com descrição, passos de reprodução, impacto e evidências mínimas necessárias.

O site atual é estático e não armazena dados submetidos pelo formulário. Mudanças futuras que adicionem APIs, formulários remotos, autenticação ou coleta de métricas devem passar por revisão específica de segurança e privacidade.

Dependências devem ser atualizadas de forma controlada. Após qualquer atualização, execute o build, a validação automática e os testes de navegação.
